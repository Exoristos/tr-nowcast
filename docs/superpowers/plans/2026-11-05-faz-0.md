# TR-Nowcast Faz 0 — Veri Hattı Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** TR-Nowcast reposunda tek komutla (`trnowcast fetch`) beş açık veri kaynağından idempotent veri çeken, kalite kontrol eden ve her serinin yayın takvimini kaydeden (as-of registry) Python veri hattı.

**Architecture:** Kaynak başına bir çekici modülü (hepsi aynı long-format DataFrame arayüzünü üretir) → ortak parquet depo + registry.json → click CLI. Birim testleri tamamen offline (fixtures); canlı ağ çağrıları `@pytest.mark.live` ile işaretlenir ve varsayılan hariç tutulur.

**Tech Stack:** Python ≥3.12, uv, pandas, pyarrow, requests, click, openpyxl; dev: pytest, ruff.

**Spec:** `docs/superpowers/specs/2026-11-05-tr-nowcast-design.md` — plan bu spec'ten gelir, executor ikisini de okur.

## Global Constraints

- Python `>=3.12`, src layout, paket adı `trnowcast`, uv ile yönetim.
- Bağımlılıklar SADECE T1'de yazılır: `pandas, pyarrow, requests, click, openpyxl, python-dateutil` + dev grubu `pytest, ruff`. Sonraki task'lar pyproject'a bağımlılık EKLEMEZ.
- Dosya yazımı Write/Edit araçlarıyla; Bash yalnızca git/uv/pytest komutları için (Mimosa hook kuralı).
- Dosya 250 satırı geçmez; `as any`/`@ts-ignore` muadilleri, boş `except`, silinmiş test yasak.
- Tüm birim testler offline: `tests/fixtures/` altında kayıtlı örnek dosyalar. Canlı çağrılar `@pytest.mark.live`, pyproject'te `addopts = "-m 'not live'"`.
- Ortak seri şeması (long format): sütunlar `date` (datetime64, ay-başı; günlük serilerde gün), `value` (float), `series_id` (str).
- Depo: `data/raw/` gitignored, `data/processed/` (parquet + registry.json) tracked.
- Commit mesajları conventional: `feat:`, `test:`, `chore:`, `docs:`.
- Kaynak modülleri ağ hatasında/beklenmedik şemada anlamlı hata mesajlı özel istisna fırlatır; sessiz boş DataFrame döndürmez.
- Her kaynak modülünün docstring'i gerçek veri URL'ini ve erişim tarihini içerir; aynı bilgi registry'ye yazılır.

## Review Focus

1. **TÜİK sayfa/değişken adı değişikliği** — fetcher deterministik `SourceError` fırlatmalı; `fetch` CLI'ı kaynağı atlayıp diğerlerini sürdürmeli, `status` hangi kaynağın neden kırıldığını göstermeli.
2. **EVDS anahtarı yokluğu** — `EVDS_API_KEY` tanımsızken fetch graceful skip + status'ta "anahtar yok" görünmeli; traceback değil bilgilendirme.
3. **Idempotent yeniden çekim** — aynı veriyi iki kez çekmek duplicate satır üretmemeli; parquet upsert-by-name + tarihe göre tekilleştirme (son değer kalır).
4. **TR yerel tarih ayrıştırma** — aylar "Oca/Sub", ondalık virgül, binlik nokta içeren fixture'lar TÜİK/EVDS testlerini kapsamalı.
5. **Aykırı değer yanlış alarmı** — 2021-2022 enflasyon zirveleri (aylık ~%5-13) kalite kontrolünde hard-fail olmamalı; eşikler registry/meta'dan gelmeli, uyarı ile hata ayrışmalı.
