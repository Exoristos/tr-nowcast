# TR-Nowcast Faz 1 — Backtest Çerçevesi + Klasik Benchmarklar

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Hileye kapalı expanding-window backtest motoru + dört klasik benchmark modeli (naive, seasonal-naive, ARIMA, ETS) + `trnowcast backtest` CLI skor tablosu; yanında EVDS kopya-ay guard'ının dilim-birleştirme düzeltmesi.

**Architecture:** Backtest motoru "as-of kesit" ilkesiyle çalışır: her hedef ay M için kesit tarihi cutoff = M'nin son günü + 2 gün (M+1'in 3'ü — TÜİK/EVDS açıklama penceresi) sabitlenir; motor her seriyi yalnız cutoff'ta yayında olan aylara kırpar (registry `publication_lag_days` üzerinden) ve modelleri bu kesitlerle besler. Modeller ortak `ModelFn` imzasını uygular; motor skorları parquet'e yazar, CLI tablo basar.

**Tech Stack:** Mevcut stack (pandas, pyarrow, click, pytest, ruff) + T13'te `statsmodels` (pyproject'a tek ekleme).

**Spec:** `docs/superpowers/specs/2026-11-05-tr-nowcast-design.md` (dürüstlük sözleşmesi + sınav dönemi kararı: girdi = tüm geçmiş, ana skor 2019→bugün, alt skor son-24-ay, README ekinde tam geçmiş).

## Global Constraints

- Dosya yazımı Write/Edit ile; Bash yalnız git/uv/pytest (Mimosa kuralı). Dosya ≤250 satır; boş `except` yasak.
- pyproject'a bağımlılık ekleme YALNIZ T13'te: `statsmodels` (temel gruba). uv.lock güncellenir (`uv lock`, `uv sync`).
- Cutoff kuralı motoru yazar (T12): `CUTOFF_OFFSET_DAYS = 2` — hedef ay M için kesit tarihi = M ay sonunun +2 günü. Sızdıran her şey bu kuralın altına gömülür; modeller asla ham parquet'e erişmez.
- Tahmin bandı: tüm modellerde **%80** (ForecastPoint.lower/upper). ARIMA/ETS: statsmodels `conf_int(alpha=0.20)`; naive/seasonal-naive: eğitim kesitindeki |hata|'nın %80 persentili (tek değer bandı: lower=point-band, upper=point+band; band < 0.2 ise 0.2).
- Sınav pencereleri kod-sabit: `SCORE_START = 2019-01-01`, `RECENT_WINDOW_MONTHS = 24` ("son 24 ay" = backtest penceresinin son 24 ayı, koşu tarihine göre değil).
- Hedef seri: `turkiye_tufe_aylik_yuzde`. Actual = aynı serinin gerçek değerleri. Skor: MAE, RMSE.
- Yeni dosyalar: `src/trnowcast/backtest.py`, `src/trnowcast/models/__init__.py`, `src/trnowcast/models/baseline.py`, `src/trnowcast/models/classic.py`, `src/trnowcast/scoring.py`.

## Review Focus

1. **Gelecek sızıntısı (ölüm hali):** motor testi — kesit cutoff'tan SONRAKİ gerçek değerler değiştirilince backtest çıktısı BİT-BİT aynı kalmalı. Bu test T12'de yazılır ve başarısız olursa motor kabul edilmez.
2. **Günlük seri kesme:** günlük seri (usd_try_gunluk, brent_gunluk) ay ortalamasına kesilir; TANIMSIZ (tam olmayan) ay ortalamaya girmez — kısmi ay None döner. Test: yarım ay verisiyle.
3. **Yayın lag'i tutarlılığı:** cutoff'ta lag'i henüz dolmamış aylar kesitte OLMAMALI (ör. lag=3 TÜFE: M+1/3 cutoff'ta M ve M+1 ayları yok, M-1 var). Test: lag=3 sahte seriyle.
4. **Model çöküşü:** ARIMA yakınsamazsa/NaN üretirse o ay `FailedForecast` sayılır — skor tablosunda ayrı satır/sayaç, sessiz 0 veya atlanma değil. Test: tekil-sabit seri ARIMA'sı.
5. **Kopya-ay birleştirme (T11):** aynı ay iki kez farklı DEĞERLE gelirse SourceError kalır; birebir EŞİT değerle gelirse sessiz dedup (meşru dilim örtüşmesi). Test: iki dilim, örtüşen ay eşit-değerli ve farklı-değerli iki senaryo.

### Task T12: Backtest motoru (as-of kesit + expanding-window)

**Files:**
- Create: `src/trnowcast/backtest.py`, `tests/test_backtest.py`

**Interfaces:**
- Consumes: T2 `load_series`, `registry` (publication_lag_days).
- Produces:
  - `@dataclass ForecastPoint: target_month: pd.Timestamp, point: float, lower: float, upper: float, model: str` (asof kesit bilgisi motorun kaydında).
  - `ModelFn = Callable[[dict[str, pd.DataFrame], pd.Timestamp], ForecastPoint]` — ilk argüman: ay-başı indeksli aylık DataFrame sözlüğü (`{seri_adı: df}`; günlük seriler aylık ortalamaya kesilmiş, eksik aylar yok — satır hiç yok), ikincisi hedef ay.
  - `asof_monthly(seri: str, cutoff: pd.Timestamp) -> pd.DataFrame` — seri adı aylık/günlük farketmez: lag'i dolmuş ayların satırları (aylık); günlükse tam ayların ortalaması.
  - `run_backtest(models: dict[str, ModelFn], target: str, start: pd.Timestamp, end: pd.Timestamp) -> pd.DataFrame` — sütunlar: `model, target_month, point, lower, upper, actual, abs_error, hit80` (actual bant aralığındaysa True). Satır sırası model→tarih artan.
  - Model çöküşü: `ModelFn` `ModelFailure` exception'ı fırlatır, motor o (model,ay) satırını `abs_error=NaN, hit80=NaN` ile yazıp devam eder (T14'te sayılır).

- [ ] **Step 1:** Failing testler (Review Focus 1, 2, 3 buraya): (a) **sızıntı kanıt testi** — yapay aylık seri + sahte ModelFn("kesitteki son değeri döndür"): kesitten sonraki gerçek değerleri değiştir → `run_backtest` çıktısı bit-bite aynı; (b) yarım günlük ay → o ay sözlükte yok; (c) lag=3 seri, cutoff M+1/3 → son girilen ay M-1; (d) `ModelFailure` → NaN satır, motor devam.
- [ ] **Step 2:** FAILED → uygula → PASS. Kapı.
- [ ] **Step 3:** Commit: `feat: as-of backtest motoru (sizinti testli)`.

**Files:**

**Interfaces:**
- Consumes: T12 `ModelFn`, `ForecastPoint`, `ModelFailure`.
- Produces:
  - `baseline.py`: `naive(...)`, `seasonal_naive(...)` — her biri `ModelFn` uyumlu. naive: kesitteki hedef serinin son değeri; seasonal_naive: 12 ay önceki değer. Bant: Global Constraint'taki kural (eğitim |hata| %80 persentil; kesit < 24 ay → ModelFailure "yetersiz geçmiş").
  - `classic.py`: `arima(...)`, `ets(...)` — statsmodels; ARIMA: `ARIMA(order=(1,0,0))` sabit, ETS: `statsmodels.tsa.holtwinters.ExponentialSmoothing` (trend="add", seasonal yok — aylık % serisi kısa/şoklu). Yakınsama/NaN → `ModelFailure`.
  - `MODELS: dict[str, ModelFn]` (models/__init__.py) — `{"naive": ..., "seasonal_naive": ..., "arima": ..., "ets": ...}`.

- [ ] **Step 1:** Failing testler (Review Focus 4 + davranış): sabit seri → naive nokta doğru, arima ModelFailure; sentetik trendli seri → arima/ets nokta tahmini; bant genişliği ≥0.2; MODELS sözlüğü 4 anahtar.
- [ ] **Step 2:** pyproject'a statsmodels ekle, `uv sync`. FAILED → uygula → PASS. Kapı.
