# TR-Nowcast Faz 3a — Canlı Nowcast + Site Veri Servisi (görsel-öncesi)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sitenin yakıtı: `trnowcast nowcast` (güncel ay için 8 modelin canlı tahmini + türetilmiş yıllık) ve `trnowcast export` (sitenin tüketeceği JSON seti); CI'ın bunları otomatik üretmesi; Cloudflare Worker iskeletinin yerelde doğrulanması. Görsel önyüz ve deploy KAPSAM DIŞI (kullanıcı onay paketine kalmış).

**Architecture:** Nowcast = backtest motorunun tek-koşum modu: hedef ay, TÜFE serisinin son değerinden sonraki ilk ay; cutoff = komut anı (bugün) — motorun as-of kuralı aynen geçerli. Çıktı JSON'ları `data/site/` altında statik dosyalar; Worker bunları asset olarak servis eder (veri güncellemesi = yeni commit, deploy = `wrangler deploy`).

**Tech Stack:** Mevcut stack + wrangler (yalnız dry-run doğrulaması için npx).

**Spec:** `docs/superpowers/specs/2026-11-05-tr-nowcast-design.md` — Hedef değişken bölümü (yıllık türetilmiş gösterilir).

## Global Constraints

- Faz 1/2 arayüzleri dokunulmaz (`ModelFn`, `run_backtest`, `asof_monthly`). Nowcast motoru `asof_monthly`'yi cutoff=bugün ile kullanır; ayrı tahmin yolu AÇMAZ.
- Hedef ay seçimi: `turkiye_tufe_aylik_yuzde` son değerinden sonraki ilk ay. TÜFE güncelse (bu ay zaten açıklanmışsa) hedef sonraki ay.
- Yıllık türetme: son 11 gerçek aylık % + hedef ay tahmini → `(∏(1+a_i/100))^(1/…)-1` DEĞİL, kümülatif: `((1+a1)(1+a2)...(1+a12)-1)*100`. Hem nokta hem bant uçları için aynı formül. Test sentetik seriyle kilitlenir.
- `nowcast` exit 0; model başına `ok: false, error` alanı (ModelFailure normal iş akışı — Faz 1 T14 kuralı). CI kırmaz.
- JSON şemaları T22/T23'ün (görsel faz) sözleşmesidir; T20'da sabitlenir ve test edilir. Alan adları snake_case, tarihler ISO.
- TSFM'ler CI'da: HF hub dizini `actions/cache` ile saklanır (anahtar chronos-2 + timesfm-3.0 sürümleri); cache miss'te indirme kabul. CPU tek-çıkarım yeterli (aylık tek hedef).
- Yeni dosyalar: `src/trnowcast/nowcast.py`, `src/trnowcast/export.py`, `.github/workflows/update.yml` güncellemesi, `site/` + `wrangler.jsonc`.

## Review Focus

1. **Nowcast cutoff dürüstlüğü:** nowcast, `run_backtest`'in as-of mekanizmasını AYNI fonksiyonla kullanmalı (`asof_monthly(seri, cutoff=bugün)`) — ikinci, gevşek bir kesit yolu olamaz. Test: nowcast çıktısındaki cutoff_date alanı motorun kullandığı kesitle birebir; hedef ay seride HÂLÂ yok (açıklanmamış) testi.
2. **Yıllık türetme doğruluğu:** sentetik 12 aylık % serisinde kümülatif formülün elle hesapla birebir eşitliği; 11'den az gerçek ay varsa (yeni seri) `yillik: null` + not, uydurma yok.
3. **CI'da TSFM başarısızlığı siteyi kırmamalı:** CI'da GPU yok; chronos/timesfm CPU'ya düşer ama yine de çökebilirse nowcast.json'da `ok:false` kalır, site verisi eksik modelle yayında. Test: monkeypatch'li çöken modelle export JSON'u hâlâ geçerli şema.
4. **Export idempotentliği:** iki üst üste export aynı baytları üretmeli (deterministik sıralama, sabit alan sırası) — CI commit gürültüsünü önler. Test: iki koşum, dosya hash'leri eşit.
5. **Paralel güvenlik:** T21 (update.yml) ile T22 (site/) ayrı dosyalar; pyproject'a hiçbir task dokunmaz (wrangler npx ile, bağımlılık eklenmez).
