# TR-Nowcast Faz 4 — Sohbet Backend'i (veriye bağlı + guardrail)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cloudflare Worker'a `/api/sohbet` POST endpoint'i: LLM yalnız site verisiyle (nowcast, skorlar, seriler) cevap verir; veri dışı soruya dürüstçe "verimde yok" der. Görsel arayüz KAPSAM DIŞI (onay bekliyor) — frontend Faz 3b'de bu API'ye bağlanır.

**Architecture:** Worker: assets servis + tek fonksiyon endpoint. POST /api/sohbet → prompt derleyici (site JSON'undan sıkışık bağlam: nowcast özeti + arena tablosu + son 12 ay seri değerleri) → Workers AI (LLM) → cevap. MOCK modu (`MOCK=1` env): LLM yerine sabit echo — testler bunsuz da koşar. Guardrail üç katman: (1) system prompt kuralları, (2) bağlam yalnız gerçek veri (uydurma alan yok), (3) çıkış doğrulaması: cevap veride OLMAYAN sayı içerirse şüpheli işaretlenir.

**Tech Stack:** TypeScript (Worker), vitest + @cloudflare/vitest-pool-workers (site/ altında ayrı npm alanı; ana Python repo etkilenmez), Workers AI `@cf/meta/llama-3.3-70b-instruct-fp8-fast` (builder güncel ücretsiz modeli doğrular).

**Spec:** `docs/superpowers/specs/2026-11-05-tr-nowcast-design.md` — sohbet katmanı: "yalnız projedeki veriyle cevap (halüsinasyon guardrail)".

## Review Focus

1. **Halüsinasyon tuzağı (ölüm hali):** veride olmayan konu (GSMH, siyaset, "yarın dolar kaç TL") → cevabın kendisi veri-dışı red kalıbıyla dönmeli; mock AI'da bile prompt derleyicinin bağlamına GSMH sayısı GİRMEMELİ (test: prompt metninde "gsmy" geçmez).
2. **Sayı doğrulama katmanı:** cevaptaki her % sayı, bağlamdaki sayılarla karşılaştırılabilir katman — cevap bağlamda OLMAYAN sayı içeriyorsa response'a `dikkat: "cevapta doğrulanamayan sayı var"` eklenir (sessiz geçilmez).
3. **Tahmin/gerçek ayrımı:** "kesin mi?" tarzı soruya cevap şablonu belirsizliği anlatmalı (bant, MAE'lerle) — kesinlik iddiası diline cevap veremez.
4. **Yatırım tavsiyesi kalkanı:** "hangi modelden alayım / yatırımlık mı" → sabit red şablonu (LLM'e bırakılmaz, kod seviyesinde).
5. **Bağımlılık hijyeni:** site/package.json yalnız wrangler/vitest/types — LLM SDK YOK (Workers AI REST/binding hâli); ana pyproject/uv.lock hiç değişmez.
