# TR-Nowcast Faz 3b — Üç Ekranın Gerçek Veriye Bağlanması + Deploy Önizleme

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stitch'ten alınan üç ekranın (TR masaüstü `index.html`, EN masaüstü `en/index.html`, EN mobil `m/index.html`) statik/süs sayılarını gerçek CI verisine bağlamak; Worker'ı User-Agent yönlendirmesiyle deploy edip workers.dev önizlemesinde Playwright kanıtı üretmek; README + LinkedIn taslağını yazmak.

**Architecture:** Sayfalar açılışta same-origin fetch ile `nowcast.json`, `scores.json`, `chart.json`, `series/*.json` okur ve DOM'a doldurur (statik fallback yok — veri gelmezse açık hata bandı; sahte sayı asla gösterilmez). Export site yönetimi yeni `chart.json` ve gerçek hesaplanan özet istatistikleri üretir. Worker `/api/sohbet` + assets + UA yönlendirme.

**Tech Stack:** Mevcut (Python export, TS worker, vitest, wrangler, Playwright).

**Spec:** `docs/superpowers/specs/2026-11-05-tr-nowcast-design.md` + `DESIGN.md` (kullanıcı kararı: Stitch nihai terminal tasarımı) + `docs/site-icerik.md` (copy-freeze).

## Global Constraints

- Tasarım değişmez: Stitch ekranlarının HTML/CSS yapısı, renkler, tipografi AYNEN kalır; yalnız veri bağlanır ve mock sayılar gerçekle değiştirilir.
- Süs sayı KALMAZ: "12 Ay MAE 0,82", "Yön %91,6", "Bant İçi %83,3", "Commit 8f2c01d", "14:30 UTC" gibi Stitch uydurmaları ya gerçekten hesaplanır ya da alan tamamen kaldırılır. Kullanıcıya hangi alanın gerçek olduğunu rapor belgeler.
- Grafik: statik SVG polyline'lar `chart.json`'dan JS ile üretilir; bant poligonu gerçek alt/üst'ten. Nokta sayısı pencere seçimine göre (12/24/tüm).
- Yıllık türetme, medyan hesabı: `nowcast.json` tek kaynak; sayfa kendi hesabını yapmaz.
- Dil yönlendirmesi yok (v1): `/` TR, `/en/` EN; mobil UA → `/m/` 302 (tr masaüstünden). TR mobil sayfa yok — bilinen boşluk, footer'da link ile masaüstüne dönüş.
- Deploy: workers.dev önizlemesi (workers_dev: true); MOCK var'ı KALDIRILIR (sohbet canlı). Custom domain (exoristos.dev) DEĞİL — o ayrı onay.
- Dosya ≤250 satır; üç HTML de büyürse JS ayrı dosyaya (`assets_root/site.js`) taşınır.

## Review Focus

1. **Süs sayı taraması:** sayfalarda gerçek veri kaynaklarıyla eşleşmeyen hiçbir statik sayı kalmamalı — denetçi, sayfadaki her rakamı JSON'larla karşılaştırır.
2. **Fetch hata yolu:** JSON 404/bozuk ise sayfa belirgin hata bandı göstermeli; boş `--`/0 ile sessiz devam YASAK.
3. **Yön tutarlılığı tanımı:** "yön isabeti" = işaret(tahmin−önceki gerçek) == işaret(gerçek−önceki gerçek); parquet'ten hesap; tanım README'de yazılı.
4. **UA yönlendirme döngüsü:** /m/ sayfası mobil UA'da kendine 302 atmamalı.
5. **Deploy sırrı:** EVDS anahtarı worker'a GİRMEZ (fetch CI'da); worker yalnız AI binding + assets.
