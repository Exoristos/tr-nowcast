Insight 1: TSFM Hypothesis

Over the last 24 months, foundation time series models (TimesFM 3.0, Chronos-2) significantly outperformed classical statistics. Zero-shot architectures adapt faster to structural regime shifts in Turkey.

Insight 2: Market Survey Superiority

Long-term MAE leader remains the CBRT Survey of Market Participants (…). Automated machine learning models have not yet systematically beaten the consensus of professional analysts.

Methodology & Data Integrity Protocol
1. Zero Lookahead Leakage: Each forecast is produced strictly using data available on the forecast date (as-of registry; future data cannot leak into past estimates).
2. Post-Hoc Revision Ban: Forecasts are produced in GitHub Actions CI runs and committed to the public repository; each run is preserved in git history, retroactive revisions after release are prohibited.
3. Open Source & Transparency: Code, model weights, and data pipelines are fully public. Independent academic research product, not financial advice.
Model Note — Bridge / MIDAS-lite

The only in-house model in the arena: Bridge / MIDAS-lite was developed from scratch by Enis Erdoğan in this project (code: src/trnowcast/models/bridge.py). It is an interpretable econometric bridge equation — 1–3 month lags of the target series are combined with 1-month lags of USD/TRY, Brent, and the FAO food index via ridge regression; the forecast band is built from the 80th percentile of training residuals. Unlike TimesFM and Chronos-2, it is not an off-the-shelf (zero-shot) model.
